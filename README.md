## About Me

I am a Full-Stack Developer focused on building practical, scalable web applications. I work close to fundamentals—clear data flow, secure APIs, and maintainable systems—while integrating AI where it adds real value.

I enjoy building MVPs fast, iterating based on real usage, and taking ownership of features end-to-end. My experience spans SaaS platforms, AI-powered learning systems, billing and operations tools, and accessibility-focused applications.
